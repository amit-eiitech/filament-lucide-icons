# Security Policy

## Supported Versions

Security fixes are applied to the latest release. Older releases may require upgrading to the latest version.

## Reporting a Vulnerability

If you discover a security vulnerability in Eii Filament Lucide Icons, please report it privately.

**Email:** info@eiitechsolutions.com

Please do not disclose security vulnerabilities through public GitHub issues.

When reporting a vulnerability, please include:

- A description of the vulnerability.
- Steps to reproduce the issue.
- Potential impact.
- Any relevant proof of concept or screenshots.

We will review the report and respond as soon as reasonably possible.

Please allow time for investigation and a potential fix before publicly disclosing the vulnerability.

Thank you for helping keep this package secure.
